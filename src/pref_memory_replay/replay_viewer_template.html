Turn-level replay

Each arm resumes the recorded transcript at the turn, at the same repo commit, and runs one agent turn (Sonnet 5.5 [1m], Claude Code 2.1.273, Docker). Memory arms mount a memory folder as the project's auto-memory: MEMORY.md is loaded into context automatically; notes count as "opened" only when the agent Read them. The judge (Opus 5.5, tool-less) sees the preference, the recorded correction (C) or the preference sentence (U), the prompt the agent saw, and the rendered turn. One run per arm.
